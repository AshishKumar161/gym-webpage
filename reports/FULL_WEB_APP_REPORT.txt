1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The A² ReVamp Gym Web Application is a full-featured, enterprise-grade SaaS 
management platform designed for fitness centers. It combines a modern, 
interactive frontend landing page and multi-role web application with a 
scalable RESTful API backend, an extensive PostgreSQL database model via 
Prisma ORM, and integrated AI fitness services.

The platform provides localized branding for Pigdambar, Indore (MP, India) 
while delivering enterprise SaaS capabilities including multi-role dashboards 
(Member, Trainer, Admin), POS & inventory management, automated AI workout/diet 
generators, subscription management, digital QR code check-ins, and multi-gateway 
payments (Razorpay & Stripe).

4. DATABASE MODEL & SCHEMA ANALYSIS (PRISMA ORM)
--------------------------------------------------------------------------------
The database is built on PostgreSQL with Prisma ORM containing 31 interconnected 
models across 6 distinct functional domains:

A. User Identity & Authentication (4 Models):
   - User                   : Core user profile (Roles: MEMBER, TRAINER, ADMIN), 
                              password hashes, verification flags, security state.
   - Trainer                : Specialized trainer bio, experience, rating, domain.
   - Session                : DB-tracked active sessions, refreshToken hash, browser, 
                              IP, OS, and token revocation controls.
   - AuditLog               : Security audit log capturing user actions, IP, timestamp.

B. Memberships, Billing & Payments (7 Models):
   - Membership             : Membership tier plans (price, duration, features).
   - Subscription           : Active member plans, status (ACTIVE, EXPIRED, FROZEN, 
                              CANCELLED), renewal dates.
   - Payment                : Financial records (subtotal, tax, discount, method, gateway).
   - Invoice                : Generated invoice billing address, GST number, PDF link.
   - Coupon                 : Percentage/Fixed discount codes with usage limits.
   - Refund                 : Gateway refund state and tracking.
   - WebhookEvent           : Idempotency log for payment gateway webhook payloads.

C. Gym Operations & Fitness Management (5 Models):
   - Attendance             : Daily member check-ins (QR code / manual), check-in times.
   - WorkoutPlan            : Assigned workout plans linked to Member & Trainer.
   - Exercise               : Specific exercises (sets, reps, target muscle, video link).
   - DietPlan               : Nutrition plans (calorie targets, water intake, macro goals).
   - Meal                   : Meal breakdowns (types, calories, protein, carbs, fats).

D. Point of Sale (POS) & Inventory System (8 Models):
   - Product                : SKU, barcode, retail price, cost price, tax rate.
   - ProductCategory        : Catalog categorizations.
   - ProductBrand           : Inventory brands.
   - Inventory              : Stock quantities, low-stock threshold triggers.
   - InventoryTransaction   : Audit trail of stock in/out/adjustments/returns.
   - Supplier               : Vendor details, contacts.
   - PurchaseOrder          : B2B purchasing from suppliers.
   - Sale & SaleItem        : Register sales receipts, walk-in or member purchases, 
                              cashier tracking.

E. Asset & Facility Management (2 Models):
   - Asset                  : Equipment inventory (tag, purchase date, warranty, status).
   - MaintenanceLog         : Equipment repair logs, costs, reported issues, resolution.

F. Communications & AI Suite (5 Models):
   - Notification           : Multi-channel notifications (In-app, Email, Push).
   - Message                : In-app chat messages between members and trainers.
   - Announcement           : Broadcast announcements targeted by role.
   - NotificationPreference : User preferences for email/push/marketing alerts.
   - AIConversation & AITokenUsage: Audit log and token usage metrics for Gemini/OpenAI.

6. API ARCHITECTURE & SECURITY ANALYSIS
--------------------------------------------------------------------------------
- Versioning & Namespacing: Standardized on `/api/v1/*` with legacy backward 
  compatibility mounts (`/auth`, `/admin`, `/trainer`, `/member`).
- OpenAPI / Swagger Docs: Full interactive API documentation available at `/api/docs`.
- Dual-Token Auth System: Short-lived JWT Access Tokens accompanied by database-bound 
  Refresh Tokens with remote session revocation capabilities.
- RBAC Enforcement: Strict middleware checks enforcing `ADMIN`, `TRAINER`, and `MEMBER` 
  role permissions on sensitive endpoints.
- Observability & Logging: Winston logger formatting JSON logs with UUID request IDs 
  for trace-level debugging.
- Resilience & Rate Limiting: Global rate limiting preventing API abuse.
